# Strings and Collections

Python includes a rich selection of built-in collection types which are often completely sufficient for even quite intricate programs without resorting to defining our own data structures.

Fundamental Built-In Collection types:
- `str`
    - immutable strings of Unicode code points
- `bytes`
    - immutable strings of bytes
- `list`
    - mutable sequences of objects
- `dict`
    - mutable mappings from keys to values
- for-loops
    - iterating over a series of items
