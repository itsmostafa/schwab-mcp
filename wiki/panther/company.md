# Panther Labs — Company Context

## Mission

"Panther makes security teams smarter and faster than attackers."

Building the AI SOC platform for modern security teams. Detection-as-Code approach, cloud-native architecture, security data lake. Alternative to legacy SIEM.

## What They've Built

- **Detection-as-Code**: detection rules written in Python, version-controlled, unit-tested
- **Cloud-native SIEM**: ingests logs at scale, stores in security data lake (Snowflake-adjacent)
- **AI SOC agents** (current 4): alert triage, interactive chat, detection code generation, text-to-search
- **Collective intelligence framework**: agents learn from analyst decisions over time

## Key Stats

- Raised: $140M
- Investors: Coatue, Lightspeed, ICONIQ Growth, Snowflake Ventures
- Founded by: security practitioners who experienced the pain firsthand
- Structure: remote-first, global

## Culture

Three core values:
1. **Create Customer Love** — customer-obsessed, engage directly
2. **Be an Owner** — initiative, outcomes, not just tasks
3. **Take Care of the Team** — collaborative, diverse, rewarding workplace

Transparent about AI use: allow AI tools in take-home work, but not during live interviews for real-time answers.

## The Vision

Enable SOC teams to cover 5-10x more data without proportionally scaling headcount. Automate the most time-intensive analyst work: alert triage, analysis, risk validation.
