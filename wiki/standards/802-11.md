# IEEE 802.11 — Wireless LAN Standard

IEEE 802.11 is the family of standards governing wireless local area network (WLAN) communication. Maintained by the IEEE, the standard has evolved continuously to increase speed and security. **Security is not native to 802.11 — it must be added via 802.11i / WPA2.**

### 802.11i — Security Amendment

**IEEE 802.11i** is the security amendment to 802.11. It defines the **WPA2** security protocol (and underpins WPA3). Key provisions:
- Mandates **CCMP (AES)** for encryption — replacing the weak WEP/TKIP.
- Supports **802.1X** (RADIUS backend) for enterprise authentication.
- Defines the **RSN (Robust Security Network)** architecture.

### Wireless Security Summary

| Protocol | Year | Encryption | Integrity | Status |
|----------|------|-----------|---------|--------|
| WEP | 1997 | RC4 (weak IV) | None | **Broken** |
| WPA | 2003 | TKIP (RC4) | Michael MIC | Deprecated |
| WPA2 (802.11i) | 2004 | CCMP (AES) | CCMP | Current standard |
| WPA3 | 2018 | CCMP / GCMP | CCMP / GCMP | Current; not widely deployed yet |

### Unlicensed Frequencies

The 2.4 GHz, 5 GHz, and 900 MHz bands are unlicensed — anyone can create devices operating within them. This explains the proliferation of consumer Wi-Fi devices and interference from non-Wi-Fi sources (microwaves, Bluetooth).

## Exam Nuance

- Wi-Fi 6 = **802.11ax**; Wi-Fi 5 = 802.11ac; Wi-Fi 4 = 802.11n.
- **802.11i** is the security standard; **WPA2** is the commercial certification name for 802.11i-compliant products.
- All 802.11 variants share the same security challenge — security is not built-in.
