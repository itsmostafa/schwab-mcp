# ISO/IEC 27002 — Code of Practice for Information Security Controls

ISO/IEC 27002 is the companion standard to ISO/IEC 27001. Where 27001 specifies **what** an ISMS
must do, 27002 provides **how** to implement the information security controls.

> **Source gap**: The *destination-cissp* source defers Security Control Frameworks to Domain 3
> (§3.3.1). This page is a stub to be enriched when Domain 3 is ingested.

## Key Facts

- Provides implementation guidance for the security controls referenced in **ISO 27001 Annex A**.
- Latest version: **ISO/IEC 27002:2022** — reorganized into 4 themes (Organizational, People, Physical, Technological controls).
- ISO 27002 is **not** a certification standard — organizations cannot be certified against it.
- Used by organizations to select and implement appropriate information security controls.

## Relationship to ISO 27001

```
ISO 27001 — ISMS Requirements Standard (certifiable)
  └── Annex A — Control objectives and controls
        └── ISO 27002 — Implementation guidance for those controls
```

## Exam-Relevant Nuance

- Key distinction: **27001 = certifiable requirements**; **27002 = implementation guidance, not certifiable**.
- Exam may ask: "An organization wants to be certified as meeting an international ISMS standard — which standard?" → **ISO 27001**.
