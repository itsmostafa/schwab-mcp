# ISO/IEC 27001 — Information Security Management System (ISMS)

ISO/IEC 27001 is the internationally recognized standard for establishing, implementing, maintaining,
and continually improving an Information Security Management System (ISMS).

> **Source gap**: The *destination-cissp* source explicitly defers Security Control Frameworks
> (including ISO 27001) to Domain 3 (§3.3.1). This page is a stub based on general CISSP
> exam knowledge. It will be enriched when Domain 3 is ingested.

## Key Facts

- Published by the **International Organization for Standardization (ISO)** and the **International Electrotechnical Commission (IEC)**.
- Specifies requirements for establishing, implementing, maintaining, and continually improving an ISMS.
- Organizations can be **certified** against ISO 27001 by an accredited certification body (unlike ISO 27002, which is guidance only).
- Latest version: **ISO/IEC 27001:2022**.

## Structure

- Follows the **Plan-Do-Check-Act (PDCA)** cycle for continuous improvement (same Deming Cycle used in risk management).
- **Annex A** contains a reference set of information security controls (linked to ISO 27002).
- Annex A is informative, not normative — organizations select controls relevant to their risk context.

## Certification vs. Compliance

| | Certification | Compliance |
|---|---|---|
| **Definition** | Third-party audit verifies conformance to the standard | Organization asserts it follows the principles |
| **Proof** | ISO 27001 certificate issued by accredited body | Internal self-assessment or customer audit |
| **Renewal** | Annual surveillance audits; re-certification every 3 years | Ongoing |

## Exam-Relevant Nuance

- ISO 27001 = the **requirements** standard (ISMS specification).
- ISO 27002 = the **code of practice** (implementation guidance for controls).
- Organizations get **certified** against 27001; 27002 is guidance only.
- When an organization adopts ISO 27001 internally as a mandatory framework, it becomes a **standard** for that organization.
