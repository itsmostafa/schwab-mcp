# NIST Cybersecurity Framework (CSF)

The NIST Cybersecurity Framework is a voluntary framework developed to help organizations manage
and reduce cybersecurity risk. It is widely adopted in both critical infrastructure and private sector.

> **Source gap**: The *destination-cissp* source explicitly defers Security Control Frameworks
> (including NIST CSF) to Domain 3 (§3.3.1). This page is a stub based on general CISSP
> exam knowledge. It will be enriched when Domain 3 is ingested.

## The 5 Core Functions

| Function | Description |
|---|---|
| **Identify** | Understand organizational context; asset management, risk assessment, governance |
| **Protect** | Implement safeguards for critical services; access control, awareness training, data security |
| **Detect** | Identify cybersecurity events; anomaly detection, continuous monitoring |
| **Respond** | Take action on detected cybersecurity events; response planning, communications |
| **Recover** | Restore capabilities after a cybersecurity incident; recovery planning, improvements |

## Implementation Tiers (1–4)

| Tier | Name | Description |
|---|---|---|
| 1 | Partial | Ad hoc, reactive; limited risk awareness |
| 2 | Risk Informed | Risk management practices exist but not organization-wide |
| 3 | Repeatable | Formally approved, policy-expressed practices; regularly updated |
| 4 | Adaptive | Continuously improved; actively adapts based on lessons learned and threat intelligence |

## Profiles

A **Framework Profile** = the current cybersecurity outcomes based on business needs, risk tolerance,
and resources. Organizations compare their "Current Profile" to a "Target Profile" to prioritize improvements.

## Exam-Relevant Nuance

- NIST CSF is **voluntary** (not mandatory for private sector, though used widely).
- The 5 functions apply to **cybersecurity risk management** broadly, not just specific technologies.
- On the exam: NIST CSF = 5 functions (Identify, Protect, Detect, Respond, Recover); NIST RMF = 7 steps.
