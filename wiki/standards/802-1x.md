# IEEE 802.1X — Port-Based Network Access Control

IEEE 802.1X defines **port-based network access control** — a mechanism to authenticate devices before granting network access at the physical or logical port level. It is used for both wired (switch port) and wireless (AP association) access control.

## Key Facts

### Three Roles

| Role | Entity | Function |
|------|--------|----------|
| **Supplicant** | Client device (laptop, phone) | Presents credentials; initiates auth |
| **Authenticator** | Switch or wireless AP | Enforces access; relays supplicant's credentials to auth server |
| **Authentication Server** | RADIUS or TACACS+ server | Validates credentials; grants or denies access |

The supplicant communicates with the authentication server via **EAP (Extensible Authentication Protocol)**, carried within EAPOL (EAP over LAN) frames to the authenticator, which forwards them to the RADIUS/TACACS+ server.

### How It Works

1. Supplicant connects to a port (switch or AP).
2. Port is initially in an **unauthorized state** — only EAPOL traffic allowed.
3. Authenticator passes EAP exchange to the authentication server.
4. If authentication succeeds, the authenticator moves the port to **authorized state** — normal traffic permitted.
5. If authentication fails, port remains unauthorized (or placed in guest VLAN).

### Relation to WPA2 Enterprise

802.1X is the **access control framework** that WPA2 Enterprise uses. When a corporate Wi-Fi network uses WPA2 with individual user credentials (not a shared PSK), it is using WPA2 + 802.1X + EAP + RADIUS.

### IEEE 802.1Q (Related)

**IEEE 802.1Q** defines **VLAN tagging** — the mechanism by which frames carry VLAN membership tags across trunk links. It is the standard that enables VLAN segmentation on switches and SDN environments. Distinct from 802.1X (access control).

## Exam Nuance

- 802.1X = **port-based NAC**; 802.1Q = **VLAN tagging**. Do not confuse them.
- EAP is the authentication **protocol**; 802.1X is the **framework** that carries it.
- The authenticator (switch/AP) does **not** validate credentials — it relays them to the RADIUS server.
- 802.1X can be used to block unpatched or non-compliant devices (posture-based NAC) before they reach the internal network.
