Rule-Based Access Control
Rule-based access control is simply a set of rules assigned to users. Look at
Table 5-20. The ruleset governs access to the numerous objects. As such, if a
subject requires access to an object, a rule will be present to allow or deny
that. For example, there’s a rule in place to only allow Alice read access to
Bob’s directory and nothing more while she has both read and write access to
her home directory.
