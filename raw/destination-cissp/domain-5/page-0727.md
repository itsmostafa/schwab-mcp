Figure 5-12: Access Control Types
Access Control Summary
Discretionary Access Control
(DAC)
 Owner determines access rules
Role-Based Access Control
(RBAC)
 Access to resources is based on user roles (e.g.,
firewall administrator, or accounts payable clerk)
Rule-Based Access Control
 Access to resources is based on a set of rules (e.g., an
Access Control List, ACL)
