Biometric Device Accuracy/Types of Errors
Biometric error types and which is worse
Unlike other types of authentication systems, biometric
systems are not 100% binary. In other words, they’re not
always 100% accurate. With a traditional
username/password authentication system, for example,
the username and password must be 100% correct for a
user to be authenticated to a system. The same cannot be
said of a system that uses physiological or behavioral
attributes for authentication.
