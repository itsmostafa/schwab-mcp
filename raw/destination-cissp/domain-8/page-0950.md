8.2.2 Code Obfuscation
CORE CONCEPTS
 Obfuscation refers to hiding or obscuring something; code obfuscation
refers to hiding or obscuring code to protect it from unauthorized
viewing or interpretation of the logic.
 Three primary types of code obfuscation: lexical, data, control flow.
Understand the term code obfuscation and the three primary types of
obfuscation
The term code obfuscation refers to hiding or obscuring code to protect it from those who are
unauthorized to view it. More specifically, code obfuscation is intentionally creating source code that
is difficult for humans to understand, which makes it difficult to reverse engineer, or it conceals the
purpose of the code. The three main types of obfuscation are outlined in Table 8-6.
