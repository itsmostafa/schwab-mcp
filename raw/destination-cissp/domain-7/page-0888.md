Understand different backup strategies and how a backup strategy fits into
an overall recovery strategy
Recovery strategies focus on several key things, including bringing systems back online quickly,
minimizing data loss, and architecting systems in a manner that precludes system downtime if a system
failure occurs.
An important component of recovery strategies is backup strategies, which focus on backing up data in
such a manner that if the primary data store is lost, corrupted, stolen, or otherwise compromised, the
data can be recovered and restored. Before diving in a bit deeper on this topic, it’s important to
understand a technical detail known as an archive bit. Within virtually every operating and associated
file system, each file will have an associated bit. The bit is simply metadata, which is data about data.
Archive Bit
An archive bit, as depicted in Figure 7-10, can be set to zero (0) or one (1), and the setting indicates if
the file needs to be backed up or not. If the archive bit is set to 0, the file does not need to be backed up;
if the archive bit is set to 1, the file needs to be backed up. When a backup is performed, the archive bit
is usually set to 0. After the backup, if any of those files are modified or if new files are created, the
archive bit is set to 1, indicating that the file needs to be backed up.
