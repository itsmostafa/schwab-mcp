Incremental Backup
An Incremental backup starts by performing a full backup, represented by the bar above Sunday. A full
backup means that every file, regardless of the archive bit setting, is backed up, and the archive bit on
each file is then set to 0. On Monday, the typical beginning of a work week, people show up and start
creating or modifying files. The archive bit associated with every new or modified file is set to 1. On
