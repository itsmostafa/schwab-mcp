7.4.1 Foundational Security Operations Concepts
CORE CONCEPTS
 Implementation of foundational security operations concepts can
significantly improve security within an organization.
 Foundational security operations concepts include: need to
know/least privilege, separation of duties (SoD) and responsibilities,
privileged account management (PAM), job rotation, and service
level agreements (SLA).
