With digital forensics, one of the primary considerations is
what’s referred to as live evidence. Live evidence is data that
is stored in a running system in places like random access
memory (RAM), CPU, cache, buffers, and so on. If the
keyboard is tapped, if the mouse is moved, and certainly if
the plug is pulled or the system is powered off, the live
evidence changes or disappears completely. Examining a
live system changes the the state of the evidence. This
fact makes it immediately clear that examination of a live
system requires expert knowledge and specialized tools to
extract live evidence and minimize contamination. As noted,
live evidence is often stored in locations like RAM, cache,
and the CPU, and if power to the system is disrupted, the
live evidence is gone.
