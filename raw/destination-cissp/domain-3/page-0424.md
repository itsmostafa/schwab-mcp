Do note that although Alice has produced a digital signature and sent it as
part of the message to Bob, if anybody intercepts that, they’ll be able to read
the message. A digital signature does not provide confidentiality—anybody
could potentially read the message, as that content hasn’t been encrypted.
Once Bob receives the message from Alice, he needs to reverse the process
by the following steps: 1. Decrypt the digital signature with Alice’s public
key. Once he’s able to do that, authenticity has been proven. Bob knows the
message came from Alice.
2. Hash the message he received (using the same hash algorithm used
by Alice).
3. Compare the hash value he calculated in step #2 with the hash value
received from Alice. If the values match, Bob will know that the
message was not altered in transit.
With authenticity and integrity verified, nonrepudiation has also been
verified. Alice cannot deny that she sent the message.
