Until the malicious code is cleared from the website, many site visitors could be impacted,
and a savvy attacker might be able to gain username/password, banking, or other sensitive
information because of the JavaScript executing in the browser.
Attackers might use XSS for any of a number of malicious reasons. For example, the JavaScript code
could be used to:  Send a copy of the victim’s browser cookies, including session cookies, which could
lead to session hijacking and taking over a user’s active session to connect to the destination resource.
 Disclose files on the victim’s computer system.
 Install malicious applications.
