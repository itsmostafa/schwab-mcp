As we mentioned earlier, lattice-based security models, like Bell–LaPadula
and Biba, can also be thought of as layer-based security models. Based upon
intersecting vertical and horizontal support elements, a lattice structure can be
envisioned as having different layers. Extrapolating this concept further, each
of the two security models can be viewed as having different layers of
security.
