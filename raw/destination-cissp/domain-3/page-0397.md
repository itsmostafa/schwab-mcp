Understand advantages and disadvantages of
asymmetric cryptography and how these compare to
symmetric cryptography
As discussion about symmetric cryptography explained, it is
very fast, but the fundamental problem with key
distribution is significant. As a result, cryptologists explored
ways to solve the key distribution problem, and in the 1970s
two of them—Diffie and Hellman—developed an idea they
called “public key cryptography.” They premised their idea
on the fact that symmetric key cryptography requires the
sender and receiver to share the same key, and they asked
“What if everybody had two keys that were related to each
other mathematically, with the mathematical linkage being
such that if something is encrypted with one key it can
never be decrypted using the same key? Rather, the other
key would need to be used.” This way, one of the keys can be
