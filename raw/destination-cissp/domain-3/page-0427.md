Who can decrypt a given CA’s digital certificate? Anybody who has the CA’s
public key can decrypt the digital certificate, and virtually every web browser
and computer operating system include the public keys of the major global
certificate authorities. Thus, virtually everybody can decrypt one of the big
CA’s digital certificates.
When exchanging public keys with others, therefore, the best practice is to do
so by sending them a copy of the digital certificate that contains the public
key. Doing so ensures that an attacker in the middle, even if they’re able to
intercept the digital certificate, can’t replace the owner’s public key with the
attacker’s public key. Only a certificate authority can modify a digital
certificate, because the CA’s private key is needed to do so.
