3.5.12 Cloud Computing Roles
CORE CONCEPTS
 Multiple computing roles relate to cloud computing: cloud consumer,
cloud provider, cloud partner, cloud broker
 The cloud consumer is always accountable for their data stored in the
cloud.
 Responsibility can be delegated to other cloud computing roles.
 Data controller = owner of data = cloud customer = accountable
 Data processor = processor of data = cloud provider or other agent of the
customer = responsible
