3.6.11 Public Key Infrastructure
CORE CONCEPTS
 Public key infrastructure (PKI) is the basis for keys to be distributed and
owners of public keys to be verified.
 The standard used to create all digital certificates is X.509.
 PKI consists of several components: certificate authority (CA),
registration authority (RA), intermediate/issuing CA, certificate DB,
certificate store.
 The root of trust in any PKI is the CA, which ultimately issues
certificates.
