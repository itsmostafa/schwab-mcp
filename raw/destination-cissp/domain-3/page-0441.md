Key Distribution
Key distribution is the practice of securely distributing keys. Methods
used could include:  out-of-band distribution (although this is not very
efficient)  key wrapping using key encrypting keys (KEK)
Key Storage
Key storage is one of the most critical—if not the most critical—aspects
of securing a cryptographic system. Two types of systems are utilized for
key storage:  Trusted Platform Module (TPM)  Hardware Security
Module (HSM)
Key Change /
Rotation
Key change/rotation refers to how often encryption keys should be
replaced.
Key Destruction
/ Disposition
Key disposition refers to how keys are handled, especially in instances
where data in the cloud is concerned. Two primary methods of key
disposition/destruction are most often used:  crypto shredding  key
destruction
Key Recovery
Key recovery refers to techniques used to recover a key. Three primary
techniques exist: split-knowledge, dual control, and key escrow.
