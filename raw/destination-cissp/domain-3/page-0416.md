Hashing
The key elements that make hashing algorithms so effective are outlined in
Table 3-45.
Fixed length digest
A message of any length can be hashed, resulting in a fixed length
message digest. For example, a 20-terabyte hard drive or a single
sentence email could be run through the same hashing algorithm and
the results will be digests (hash values) of exactly the same length.

below. Any length input always equals the same length output.
One-way
Hashing relies on one-way mathematical functions that generate an
output – a fixed length message digest (hash value) – that represent
the input, but it is NOT possible to go backwards and figure out the
original input. In short, it is not possible to determine the input of
a hashing algorithm by inspecting the output.
