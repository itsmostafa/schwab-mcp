Any block mode cipher, like DES or AES, for example, will
support the five modes listed in Table 3-38. Specifics worth
noting about each mode are noted in the “Characteristics’”
column. Depending on the need, it might make sense to
use one block mode over another. For example, for the
encryption of short, nonrepeatable amounts of characters
or numbers, ECB works very well, because it is very fast.
However, for something like email or text messaging, or
anything that might include the same text or numbers, ECB
is not very secure. Due to its lack of use of an IV, the same
text would result in the same ciphertext being produced,
and patterns would emerge, making it susceptible to
cryptanalytic attacks and successful deciphering.
For email and longer messages, CBC, CFB, and OFB all work
well, because each cipher mode employs an IV as part of the
encryption process.
