Table 1-27: STRIDE Model
PASTA
Process for Attack Simulation and Threat Analysis (PASTA),
contrary to STRIDE, is an attacker-focused, risk-centric
methodology. It is much more detailed than STRIDE and
performs threat analysis from a strategic perspective that
includes input from governance, operations, architecture,
and development. This is done from both business and
technical viewpoints.
