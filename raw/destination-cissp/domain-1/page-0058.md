1.2 Understand and apply security concepts
CORE CONCEPTS
 Security must support the business in achieving its goals and
objectives
 Security must increase the value of the organization
As outlined in the introduction, the role of security has
evolved to become more fully integrated with business
processes. For example, for many years, the IT or
Information Security function didn’t consider physical
security to be part of their purview. However, there are a lot
of physical assets that an organization owns that don’t
strictly relate to data—like people—that need protection.
Security focuses on anything that represents value, better
referred to as assets, and implements controls that
ultimately increase the value of those assets. Security should
not focus only on information, or data, as this is just one
example of assets that represent value to organizations and
therefore need to be protected based on that value.
