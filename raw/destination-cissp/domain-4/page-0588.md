Table 4-32 outlines different IEEE 802.11 specifications, starting
with 802.11 and progressing to one of the latest: 802.11bn (Wi-Fi
8). This is essentially a look down wireless memory lane. Each
variation of wireless is noted, along with the frequency range(s)
a given specification covers as well as the maximum achievable
speed. However, as noted above, each specification shares the
same security concern—security is not native to any of them.
Note that at the time of writing, 802.11be is expected to be
approved late in 2024, while 802.11bn is expected to be
approved in 2028.
