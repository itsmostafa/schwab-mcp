What Is a Network?
A network is at least two devices that are connected to each
other. Like people, in order to communicate, these devices
must be able to speak a common language (which is what a
protocol does), and common rules of communication must be
followed.
What Is a Protocol?
The common rules of network communication are called
protocols. A protocol is simply a standard set of rules that are
understood, conformed to, and abided by so that two or more
devices on a network can communicate. Protocols allow
messages to be sent and received, interpreted, and acted upon,
and all of this takes place in the context of what’s known as the
Open System Interconnection (OSI) model.
