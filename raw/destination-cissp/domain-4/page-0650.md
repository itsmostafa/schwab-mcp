4.3.3 SSL/TLS
CORE CONCEPTS
 Secure Sockets Layer/Transport Layer Security (SSL/TLS) provide secure
client to server connections; the two names refer to the same thing, but
TLS is now the proper standard and most current version, as SSL is
obsolete.
 DROWN attack is a major threat to SSLv2.
 SSL/TLS connection steps: client hello, server hello, creation and sharing
of session key, establishment of secure session.
 Asymmetric cryptography is used to encrypt the symmetric session key
created by the client.
 Unencrypted SSL sessions can exist, where a browser and server
authenticate to one another, but the communications channel is not
encrypted.
