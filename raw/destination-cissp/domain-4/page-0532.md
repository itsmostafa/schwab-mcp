IGMP
Internet Group Management Protocol is used to establish and
manage group memberships for hosts, routers, and similar
devices.
IPsec
IPsec is a tunneling protocol that supports authentication of
other Layer 3 devices as well as encryption. It’s discussed in more
detail in section 4.3.2.
OSPF
Open Shortest Path First is a routing protocol used by routers to
manage and direct network traffic properly and efficiently. OSPF
includes security features that make it a more secure routing
protocol than others.
