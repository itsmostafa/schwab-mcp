What protocol is often used to quickly determine if
network communication problems exist?
In addition to the Layer 3 protocols mentioned above, Internet
Control Message Protocol (ICMP) is another very significant
Layer 3 protocol. ICMP is used for the messaging aspects of
networking and acts as a helper protocol by facilitating
reporting issues over ICMP messages. For example, an ICMP
“destination host unreachable” message denotes that the
packet destination couldn’t be reached. However, note that
ICMP can also be used maliciously. An attacker can use the
ping utility to identify if a host is “alive” and reachable in any
given network. Traceroute is a utility that maps the hosts
between a source and destination and provides the traffic path
taken. Both commands are often utilized as part of the
reconnaissance phase of an attack, and this explains why it is
standard practice for organizations to filter incoming ICMP
packets at the firewall.
