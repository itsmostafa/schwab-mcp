Context-Based Access Control (CBAC)
CBAC is a feature of firewall software that intelligently filters
TCP and UDP packets based on application layer protocol
session information. It allows for deep traffic inspection and
filtering to take place, that is, it’s able to detect potential DDoS
attacks or provide advanced statistics about the various
connections and protocols used.
