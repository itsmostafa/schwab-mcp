The Network layer handles two very basic but important
responsibilities—fragmentation and IP addressing.
Fragmentation provides the ability to take data and break it up
into packets—chunks of data—and then allow those packets to
be delivered to their destination via IP addressing. The IP
protocol within TCP/IP specifically handles most of the
responsibilities found at the Network layer. In this context, ARP
and RARP are heavily relied upon. If data is leaving the network,
the sending device’s MAC address is mapped to an IP address;
if data is entering the network, the IP address is mapped to the
receiving device’s MAC address.
