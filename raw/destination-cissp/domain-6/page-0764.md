Unit
Testing
Examines and tests individual components of an
application. As specific aspects (units) of functionality are
finished, they can be tested.
Interface
Testing
As more and more individual components are built and
tested, interface testing can take place. Interfaces are
standardized, defined ways that units connect and
communicate with each other. Interface testing serves to
verify components connect properly.
Integration
Testing
Integration testing focuses on testing component
groups (groups of software units) together.
System
Testing
System testing tests the integrated system (the whole
system).
