To test this password input box more efficiently, boundary
value analysis could be used. Boundary value analysis
requires first identifying where there are changes in
behavior—these are called boundaries. In the given
example, there is a change in behavior between 7- and 8-
character lengths—7 should be rejected, and 8 should be
accepted. There is a second boundary between 16- and 17-
character lengths—16 should be accepted and 17 should be
rejected. Once the boundaries have been identified, testing
can be focused on either side of the boundaries, as this is
where there are most likely to be bugs.
