About the job
The Mission

Panther is building the future of SOC automation through AI agents that fundamentally change how security teams operate. Our vision is to enable SOC teams to cover 5-10x more data without proportionally scaling headcount by automating the most time-intensive analyst work: alert triage, analysis, and risk validation. We're building intelligent agents that leverage our data pipeline and alerting capabilities to create a SOC team extension that gets smarter over time through collective intelligence.

The Team + Role

You'll work directly with our Founder & CTO to build AI-powered SOC analyst solutions that sit at the intersection of security and cutting-edge ML and agentic engineering. This is a customer-centric product engineering role where you'll engage directly with security teams to understand their pain points and build agent-based tools that solve real problems. We're building autonomous security capabilities for alert triage, interactive chat, detection code generation, and text-to-search, all deeply integrated with Panther's ingestion pipeline. This role is ideal for engineers who combine strong development skills with security domain knowledge in SOC automation and XDR.

What You'll Need

Technical Expertise:

Deep understanding of embeddings, vector databases, RAG, and agentic engineering frameworks
Strong software development skills with the ability to build production-grade systems
Experience with ML/AI agent architectures and feedback loops

Domain Knowledge:

Security expertise with hands-on knowledge of SOC workflows, alert triage, and threat analysis
Understanding of XDR platforms and security automation challenges
Passion for solving security team operational problems through intelligent automation

Mindset:

Customer-obsessed: You thrive on engaging directly with customers to listen, learn, and build innovation alongside them
Startup mentality: You're comfortable with ambiguity and excited to build novel solutions in a fast-moving environment
Product vision: You can translate technical capabilities into meaningful SOC team outcomes

What You'll Do

Build and enhance autonomous AI agents spanning alert triage, interactive chat, detection code generation, and text-to-search capabilities
Create feedback loops between agents that integrate seamlessly with Panther's ingestion pipeline
Develop our collective intelligence framework that enables agents to learn from observations and improve accuracy over time
Partner directly with customers to understand SOC team workflows and validate agent effectiveness
Expand our current suite of 4 SOC agents and design new agent capabilities that extend SOC team capacity
Drive measurable impact: reduce triage time significantly and enable security teams to handle exponentially more data with existing resources
